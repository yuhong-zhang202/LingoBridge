## 一、项目现状（一页纸）

**产品**：LingoBridge，面向中国雅思口语备考生的练习 App（移动端 Web / PWA）。核心理念——把用户真实的生活故事转成可即兴表达的口语素材，走「录音→整理→匹配真题→侧重点分析→对话练习→反馈收藏」闭环，不背模板、不刷题库。匹配的护城河是「观察点 taxonomy」（6 维度 ~44 观察点，两段式召回+重排）。

**技术栈**：Next.js（App Router）+ PWA · Supabase（Postgres + RLS + 匿名 auth）· 千问 qwen-plus/qwen-flash（LLM）· 豆包 ASR（转写）· ffmpeg 服务端转码。

- 匹配三段式（萃取→三层漏斗召回→相关性重排）、观察点 taxonomy 护城河、为什么不用「全塞一个调用」、为什么不加「维度匹配加分公式」——见 `docs/匹配链路-权威文档.md`（历史推导详见 `HANDOVER-2026-06-06.md`）。
- 产品红线（如「当季真题不编题」第 8 条）——`docs/PRODUCT_INVARIANTS.md`。
- AI 分工：LLM 全用千问 qwen-plus/qwen-flash（DashScope，北京 key + 北京 base_url，地区须一致）、ASR 用豆包；`lib/api-logger.ts` 记每次调用用量+人民币成本到 `api_usage_logs`，看板在 `/dashboard`（需管理员登录）。
- 安全红线：`supabase-server.ts` / `corpus-server.ts` 含 service_role key，首行必须 `import 'server-only'`，禁被任何客户端链路引用；改后 `npm run build` + grep `.next/static` 确认无泄露。

**部署步骤 / 环境变量**
- 全部见 `docs/部署交接-香港PaaS.md`。运维铁律：**只点「重新部署」，永远别点「重新上传」**（后者识别成静态站→全站 404，第 11 节事故）；**内测期禁止扩容**（第 12 节，进程内信号量单实例才成立）。
- 迁库/增量迁移：`npm run db:push`（直连 Postgres 迁移器，`.env.local` 配 `SUPABASE_DB_URL`=新加坡 Session pooler 连接串）；整库搬家用 dump/restore（保留 auth.users）。详见 `Supabase迁移-法兰克福到新加坡.md`（若保留）+ 最近 commit `1380212` runbook。

**DB 迁移经验（血泪教训，别重蹈）**
- **`if not exists` 在列级别是静默漏洞**：`create table if not exists` 表已存在时整段跳过、连里面的列一起跳过。生产库迁移对账必须做**对象级**（列/函数/触发器/policy），不能只查表名。
- `supabase_migrations.schema_migrations` 曾不可读=本项目历史从未用 `supabase db push`、手工贴 SQL 是漂移成因（现已改用 `db:push`）。
- Supabase 嵌套查询 to-one 返回**对象**不是数组，`.map` 会崩；写查询先判 to-one/to-many。
- 匿名用户角色是 `authenticated`（带 `is_anonymous`）不是 `anon`；SQL Editor 用 postgres 身份、无 `auth.uid()`，依赖它的 RPC 在 Editor 测会返 0（不是 bug）。

**团队协作约定** —— 全部在 `CLAUDE.md`（语言全中文、派角色硬性表、验证纪律六条）。台账唯一写入者是 `recorder`。

**重要历史决策**
- 部署选香港 PaaS 而非 Vercel（大陆无节点）；Supabase 迁新加坡降延迟（但对国内不一定更快，见 A3/B11）。
- 登录方案：内测「方案 B 无登录墙」（匿名优先 + 白名单挡注册）；上架 iOS 走 Apple Sign In + 匿名账号升级（user_id 不变、数据自动保留），需 Apple Developer 付费账号。
- 换季导入流程（每年 1/5/9）：出新 enriched JSON + remap.vN → C 导入 → D remap → E 改 `CURRENT_SEASON` 常量 → G 体检；换季后**必须按新季重标 ranking 金标**（见 A 类）。runbook 见 `Claude-Code操作指令-2026-05题库导入.md`（含 2026-05 三处实测订正）。
- 迁移前 matching 用 Claude Sonnet ≈¥0.038/次 → 迁千问后约 1/30。
